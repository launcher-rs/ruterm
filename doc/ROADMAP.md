# RuTerm 路线图

> 对标对象：[RustTerm-Egui](https://github.com/luckbloke/RustTerm-Egui)（egui 0.36 + alacritty_terminal 原型，
> 源码见 `temp/RustTerm-Egui`）。功能只收**远程连接相关**且我们目前没有的，按「价值 / 成本」排序；
> 界面与交互上的可借鉴点单列一节（见「界面与交互」）。
> 已具备的能力不重复列，明确不做的见「非目标」。
>
> 定位：**远程连接工具，终端为核心**。SSH / Telnet 是远程连接，VNC / RDP / SPICE 也是，
> 所以远程桌面保留在 P2（不承诺排期）；而 AI 助手、内置浏览器、URL 用浏览器打开属于终端之外
> 的另一类产品能力，不做。

## 现状对照（速览）

| 能力 | RustTerm-Egui | RuTerm | 结论 |
|---|---|---|---|
| 终端内查找 | Ctrl+F 高亮 + 上/下跳转 | Ctrl+F 查找条（字面量 / 正则） | **已补** |
| 多终端联动 | 批量执行 + 同步输入 | 同步输入 + 命令广播（菜单 + 二次确认） | **已补** |
| Telnet / Ping | 原始 TCP + 最小 IAC；PTY 跑 ping | Telnet 会话（最小 IAC + NAWS）、主机右键 Ping / 路由追踪 | **已补** |
| 中英文界面 | i18n 静态词典 + 语言切换 | 简中 / English 即时切换 | **已补** |
| 键宏 | 组合键 → 字节流，导入导出 | 管理器：触发键 + 多步序列 / 延迟、导入导出 | **已补** |
| 本地文件页 | 单栏本机目录浏览器 | 只有远端 SFTP | 补 |
| 远程桌面 | VNC / RDP / SPICE 真实实现 | VNC / RDP 标签，可存为常用主机；RDP 含双向剪贴板与动态分辨率 | VNC / RDP **已补**（RDP 实机待复核）；SPICE 依赖受阻（见 P2） |
| 局域网发现 | 无 | 按需扫私有网段，列出开放 22/23/3389/5900 的主机 | **我们领先** |
| 加密凭据库 | 明文 `sessions.json` | 加密库 + 字段加密 | **我们领先** |
| 主机指纹 | TOFU（known_hosts 文本） | TOFU 入库、跳板逐跳校验 | **我们领先** |
| 端口转发 | 仅本机 TCP 直连中转 | -L / -R / -D（SOCKS5） | **我们领先** |
| 分屏 / 托盘 / WSL / 状态栏指标 / ZMODEM / 单实例 | 无 | 有 | **我们领先** |

## 界面与交互（可借鉴清单）

> 先说结论：原型的**视觉皮**不值得抄——egui 默认控件、emoji 当图标、深色硬编码（`#141821`），
> 切换主题时终端内外不同步。我们的框架主题、`IconName` 图标集、纯图标轨更整齐。
> 真正值得借的是**信息怎么摆、反馈放在哪**：下面这张表。
> 「排期」列与 P0/P1/P2 同级；`S`＝半天到一天。

**查找条的取值边界**：rgpui-term 只给 `SearchStatus { Idle, Invalid, NotFound, Matched }`
与 `search_current()`，没有总匹配数。所以别照抄原型的「3/17」计数，改成状态文案
（「未找到」「正则非法」；命中就静默高亮 + 上下跳转）。原型只支持子串，我们反而能多给
一个「正则」开关：`search()` 走正则，`search_literal()` 走字面量。
顺带一提，rgpui-term 首次搜索从光标位置向后找并自动回绕，和原型「先落在最新输出附近」的手感一致，不用额外做。

**沿用的设计约定**（写进后续所有界面改动）：

1. 颜色只取主题语义色，终端配色走 `ThemeManager` 预设，不学原型硬编码；
2. 图标只从 `IconName` 里选，不混 emoji（原型 🖥/🌐/📁/🔍 字号与基线都不齐）；
3. 低频操作悬停揭示、高频操作常显，但键盘等价路径必须有（关标签要有快捷键）；
4. 反馈尽量落在操作点：能就地提示就别只改状态栏，状态栏是兜底不是主渠道；
5. 非显然控件写「后果型」tooltip，而不是复述名字——原型的跳板机说明、
   「密码（可空，连接后提示）」都是好例子；
6. 不可用就禁用 + 说明原因（tooltip），不要隐藏，也不要点了没反应；
7. 不照抄装饰：原型「跟随系统」主题没有处理逻辑，`🎬 开始录制` 是死按钮。

**不借鉴**（我们已经更好，或与产品调性不合）：

- 密集工具栏（12 个「图标 + 文字」竖排按钮）——我们刚改成纯图标轨 + 悬停提示，别回退；
- 常驻快捷连接条（地址 / 跳板机 / 认证 / 凭据 / 连接 挤成一行）——吃终端高度，
  会话菜单 + 主机表单已覆盖；
- 设置窗口的折叠分组 +「保存并应用」——我们左导航分页、即时生效更好；
- 状态栏塞快捷键提示（`Ctrl+N 新建 | …`）——菜单项自带快捷键徽标；
- emoji 图标、硬编码深色、把 AI 状态常驻状态栏。

## P0 · 近期（低成本、直接补短板）

- [x] **终端内查找（Ctrl+F）** — `S` — 已完成
  活动终端顶部内联查找条：输入即高亮（含回滚历史），回车 / Shift+回车上下跳转，
  `Aa` 切换字面量 / 正则，Esc 收起并清高亮。状态文案只区分「未找到 / 正则无效」，
  不显示总匹配数（rgpui-term 不给计数）。实现走 `TerminalView::search` / `search_literal`
  排队下发，`Event::SearchUpdated` 回来后再重绘查找条。
- [x] **同步输入 / 命令广播** — `M` — 已完成
  活动终端按键镜像到其它终端，以及「命令发到所有会话」。实现没有动会话层的
  `SessionCommand`，而是在 `Terminal::add_middleware` 上挂 `MirrorInput`：所有输入本就
  经过中间件，`on_input` 只观察不改写，把非 `Programmatic` 的键盘 / 文本 / 粘贴字节投进
  tokio 通道；UI 侧 `mirror_input` 只在开关打开且来源是活动标签时用 `Terminal::input()`
  （Programmatic，天然不回流）写进其它在线会话。粘贴会先剥掉本终端包的 bracketed-paste
  标记、还原为纯文本再分发，避免目标没开该模式时露出转义序列。
  「命令发到所有会话…」在「终端」菜单，弹窗列清目标会话名，勾选确认后才可发送；
  已结束 / 连接失败的会话跳过。同步输入的状态在状态栏右侧常驻一个可点击的指示，
  可用会话不足两个时自动关闭（危险命令拦截仍后置）。
- [x] **Telnet 会话** — `M`
  新增轻量 TCP 后端（最小 IAC 协商：拒绝 0xFF 0xFA 子协商、回 WONT/DONT），

  协议选择存加密库 `settings` 的 `protocols` 键（不动 hosts 列，沿用 proxy_jump 的既有先例），
  断线横幅 / 回车重连 / 自动重连与 SSH 同形（`Resume::Telnet`）；Telnet 主机不参与跳板机与
  SSH 认证字段，标签也不挂 SFTP/转发能力。侧栏以 Globe 图标 + `Telnet · host:port` 副标题区分。
- [x] **中英文界面** — `M` — 已完成
  加 `tr!` 宏 + 库内 `language` 设置，先覆盖菜单 / 标题栏 / 设置 / 状态栏 / 文件与转发页，
  终端内与提示文案后续增量替换。参考词条表：`temp/RustTerm-Egui/src/i18n.rs`（约 90 条）。

## P1 · 中期（差异化能力）

- [x] **键宏** — `M` — 已完成

  `intercept_macro_key` 顶部被吞，不会被全局快捷键或已绑宏抢走。

  `stop_propagation` 并逐步骤 `Terminal::input`（Programmatic，不回流镜像中间件），步间按每步延迟等待。
  数据存加密库 `settings.macros`，库不可用时降级 `settings.json`。

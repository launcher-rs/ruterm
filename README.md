# RuTerm

面向开发者的开源远程连接工具（SSH 客户端），基于 [rgpui](https://crates.io/crates/rgpui) +
[rgpui-term](https://crates.io/crates/rgpui-term) 外接 IO 后端构建。

GUI 会话管理器形态：左侧持久化的主机账号列表，点账号即连；右侧多标签终端。
也兼容一次性命令行快速连接（带目标参数时启动即连上该主机）。

## 功能现状

- **SSH 会话**：russh 客户端 + 交互式 PTY（`xterm-256color`），网络 IO 全在 tokio 运行时，UI 线程零阻塞。
- **三种认证**：SSH Agent / 私钥 / 密码。私钥可选**本地文件**（只存路径；可手输或「浏览…」系统文件对话框选取）
  或**内嵌到加密库**（导入 PEM 原文，与密码同级的 AES-256-GCM 字段加密后入库，随库走、不怕文件被挪走；
  加密库不可用时内嵌选项禁用，绝不降级为明文落盘）。加密私钥可在表单直填口令或连接时自动弹口令窗；
  口令与密码均可勾选"保存"，加密存入本地凭据库，默认仅本次内存持有。
  这两处密码框（主机表单的私钥口令、连接时的密码/口令面板）右侧带眼睛按钮，就地切换掩码与明文，
  状态按框独立记忆、关掉表单即复位；解锁与设置主密码的弹窗**不给切换**——主密码不该有回显的机会。
- **主机指纹校验**：TOFU known_hosts 直接存入加密库的 `known_hosts` 表；指纹不符、写入或查询失败一律拒绝连接（fail-closed，防中间人）。
- **Telnet 会话**：明文 TCP + 最小 IAC 协商（`src/telnet.rs`）。服务端 `WILL/DO` 只接受 ECHO / SGA，
  其余回 `DONT/WONT`；子协商（`0xFF 0xFA … 0xFF 0xF0`）整段丢弃，不会在屏幕上漏出协商垃圾；
  主动声明 **NAWS** 并把行列数随窗口变化上报（BBS / 全屏程序据此排版）；上行数据里的 `0xFF` 按
  RFC 854 双写转义。主机表单顶部「协议」分段控件在 SSH / Telnet 间切换，切到 Telnet 时端口默认 23、
  用户名与认证/私钥/跳板机字段一并隐藏（明文会话不带 SSH 凭据）。渲染与 SSH 共用 rgpui-term 外接 IO 后端，
  断线横幅、回车重连、自动重连行为一致；协议选择记在加密库 `settings` 的 `protocols` 键，不额外改主机表结构。
- **本地终端**：与 SSH 并列的本地 + 远程统一终端。`TerminalBuilder::new` 走 rgpui-term 内置 ConPTY 后端
  拉起本机 shell，入口是主机列表树顶的「本地终端」**折叠分组**：「会话」菜单 →「本地终端…」或 `Ctrl+Shift+T` 会开列表第一项。
  分组下逐条列出探测到的 shell（PowerShell 7 / Windows PowerShell / Git Bash / 命令提示符 / WSL），
  **WSL 按发行版逐条列出**（`WSL · Debian`、`WSL · docker-desktop`……，启动参数 `-d <发行版>`），
  每条左边是该 exe 的**系统默认图标**，点一下即开对应终端。启动后后台静默扫一次（WSL 需起一次 `wsl.exe`），
  「一键扫描」可在分组右键菜单或设置「终端」分页手动刷新。
  右键任一条可**重命名**（只改侧边栏与标签上的叫法，留空恢复系统名），也可**设置起始目录**
  （右键「起始目录…」，可从系统目录对话框选，留空恢复进程当前目录；目录不存在拒绝保存，
  事后被删则静默回落到当前目录），还可配**启动参数**（「启动参数…」，空格分隔、含空格的路径用双引号）
  与**环境变量**（「环境变量…」，多行 `KEY=VALUE`，`#` 注释忽略，键名不合法时带行号拒绝保存），
  三者都可右键一键清除；
  自定义名、起始目录、参数与环境变量按 profile id（路径 + 参数）持久化到加密库 `settings.local_shells`
  （库不可用时退回 `settings.json`），扫描重建列表后仍然生效。标签名即 shell 名（或自定义名），
  shell 退出（`exit` / Ctrl+D / 被杀）自动收标签；进程拉起与通道握手在后台 await，**成功才落标签**，失败只写状态栏。
- **网络诊断**：主机右键菜单的「Ping」/「路由追踪」在本机 PTY 里跑系统命令（Windows 用 `cmd /k ping -t <host>` /
  `tracert <host>`，命令跑完停在提示符，标签不会被「shell 退出即收」规则关掉），输出即终端内容，
  复用本地终端的查找 / 选中 / 滚动。主机名先过白名单（字母数字与 `.-:_`，IPv6 字面量的方括号自动去掉）
  再拼命令行，空白 / 引号 / 管道一律拒绝；非 Windows 的 PTY 后端传不了参数，点了只给状态栏提示。
- **空工作区首页**：没有会话时主区不是一行灰字，而是品牌大字 + 主机搜索 +「新建主机」/「本地终端」入口 +
  「最近连接」卡片（复用「会话 → 最近连接」的最近记录，最多 6 条，点一下直接连接）。首页搜索只在主区过滤
  展示名 / `user@host:port`，不影响左侧主机列表；清空后回到最近连接。
- **多标签会话**：标签栏在主区顶部，平铺式标签（不描边、标签间无空隙），点击切换、`×` 关闭；远端 `exit`、断线不再自动收标签——
  终端内容原样保留，顶部浮出「远程通道已关闭」横幅，**按回车或点「重新连接」在原标签内重建会话**（WindTerm 式），
  横幅第二行直接显示断开原因原文（多行压成一行，过长截断），旁边「复制错误」把未截断的全文写进剪贴板、状态栏回执「错误已复制到剪贴板」；
  认证被拒等失败收场不提供重连、提示回列表重新点击；结束的标签在标题前带危险色圆点，后台也能一眼看到。
  标签可直接**拖动排序**（拖动超过阈值后出现跟随光标的缩略标签，松手落到哪个标签就占它的位置，
  落到标签栏空白处＝挪到最末；只改顺序，不影响会话与分屏配对）；
  标签多到超出可见宽度时标签栏**横向滚动**（滚轮直接滚，滚轮方向沿容器轴向），
  切标签 / 新建标签 / 关闭标签后自动把目标滚进可视区；
  `Ctrl+Tab` / `Ctrl+Shift+Tab`（或 `Ctrl+PageDown` / `Ctrl+PageUp`）在标签间循环切换，同时把焦点交给目标终端。
  标签标题**跟着终端走**：终端上报 OSC 0/2 标题（`pwsh`、`vim`、`ssh user@host` 都会改）即刻换成标签名，
  标题左侧面包屑取 `Terminal::breadcrumb_text`；**双击标签就地改名**（标题位置换成输入框，全选预填当前名，
  回车 / 失焦提交、`Esc` 取消、提交空名＝撤销改名回到终端上报的标题），改名只影响这条会话、不落库；
  **中键点标签直接关闭**（浏览器肌肉记忆），鼠标悬停的提示写明「单击切换 · 双击重命名 · 中键关闭」。
  `Ctrl+W` 留给 shell 做删词（在 `Terminal` 上下文用 `NoAction` 抢占后原样进 PTY），
  关标签用不冲突的 `Ctrl+Shift+W`，或点活动标签上的 `×`。
- **终端内查找（Ctrl+F）**：活动终端顶部展开查找条，输入即高亮，搜索范围含回滚历史
  （回车下一个 / Shift+回车上一个，也可点上 / 下按钮）；`Aa` 切换字面量与正则（默认字面量，
  `foo(bar)` 不会被当成正则）。找不到时显示「未找到」、正则写错显示「正则无效」并禁用跳转按钮——
  rgpui-term 只给匹配状态不给总数，所以不做「第几个 / 共几个」计数。Esc 或 `×` 收起查找条、
  清掉高亮并把焦点交回终端；切标签会把同一关键词带到新终端。
- **同步输入 / 命令广播**：「终端」菜单 →「同步输入」把活动终端里的按键与粘贴实时写进其它在线会话
  （至少两个可用会话才能打开），状态栏右侧亮起「同步输入」指示，点它即可关闭；会话落到不足两个时自动关。
  「命令发到所有会话…」弹出一条命令，勾选确认后以回车写入每个可用会话（已结束 / 连接失败的跳过），
  弹窗里列清目标会话名。粘贴在镜像前会还原成纯文本，避免 bracketed-paste 转义串进没开该模式的会话。
- **键宏**：「终端」菜单 →「键宏…」（`Ctrl+Shift+M`）打开管理器：每行一条宏（启用开关 / 名称 /
  触发键 / 步数 / 使用次数），带搜索与 ▶ 执行 / 编辑 / 两步确认删除；编辑表单可加多步「发送内容 + 步后延迟」，
  转义 `\n` 回车、`\t` Tab、`\e` ESC、`\\` 反斜杠，其余按字面发送。触发键**点一下录入框再按下组合键即录好**
  （与设置快捷键同一套交互，× 清空＝不绑键，不用手打 `ctrl-alt-1` 这种串）；录制期间按键被整条拦截，
  不会被全局快捷键或已绑的宏抢走，Esc 退出录制。触发键带 Ctrl / Alt（或 F1–F12），
  只在终端持有焦点时拦截，命中即吞掉按键（不会再把 Ctrl+字母当控制字符送进 shell）；
  发送复用同步输入的同一条写入通道（Programmatic 来源，不回流镜像）。列表支持 JSON 导入 / 导出，
  数据存加密库 `settings` 表 `macros` 键。用法与示例见下文「键宏使用示例」。
- **断线自动重连**：连接意外中断（断网 / 服务端掉线）后按 1 / 2 / 5 / 10 / 20 秒退避自动重连，最多连续 5 次，
  横幅显示「第几次、几秒后」并可随时取消；会话稳定运行 30 秒后计数重置。远端主动 `exit` 与首次连接失败不触发自动重连。
  建连（DNS / TCP / 握手 / 认证 / 开 shell）有可配置超时（默认 15 秒），超时即结束本次尝试。
  活动标签用主题语义色 `tab_active` 打底 + 顶部 2px 强调线，与 `tab_bar` 底色分开，明暗两套都一眼可辨；只有活动标签显示 `×`，非活动标签不显示。
- **分屏**：`Ctrl+Shift+D` 左右 / `Ctrl+Shift+E` 上下，把当前标签与相邻标签配成一对并排显示（「视图」菜单同入口）；
  同方向再按一次退出分屏，反方向直接换向。点哪一侧就切到哪个标签并把焦点交给它的终端，活动一侧带强调色边框；
  中间分隔条可拖拽调整比例（两侧最小 240px）。切换到配对外标签或关闭任一侧标签时自动回到单屏。
- **主机列表（分组树）**：树顶是「本地终端」折叠分组（子项为各本机 shell），其下是各分组（文件夹）与「未分组」——折叠三角 +
  文件夹图标 + 组名 + 主机数，组内主机再带认证方式图标（Agent / 私钥 / 密码各不相同）、展示名与 `user@host:port`。
  新建 / 编辑 / 删除 / 移动到分组 / 新建·重命名·删除分组全部收在**右键菜单**（主机行、分组行、列表空白处皆可），
  「本地终端」分组的折叠态同样会记住（重启后保持收起 / 展开）。顶部不再放常驻的「+ 新建主机」大按钮。删除分组只把主机退回「未分组」，**绝不删主机**；
  删除主机弹二次确认（已保存的密码/口令一并从加密库清除）。新建/编辑为**居中弹窗**表单
  （分组 / 跳板机并排，弹窗高度随窗口封顶、内容超高时字段区自行滚动），
  表单内含「分组」下拉：在分组上右键「新建主机」会预选该组，保存即落进去并自动展开该组；编辑时可改归属。
  点一下主机行即开会话；搜索框按展示名或 `user@host:port` 实时过滤，★ 收藏置顶并持久化。
  组内可手动排序：主机行右键「上移一位 / 下移一位 / 移到组内最前」，结果存进 `sidebar` 键；
  收藏与非收藏各自成桶（★ 恒在桶上方，排序不会把普通主机插到收藏中间）；同一右键菜单里还有
  「Ping」「路由追踪」，点一下就在本地终端里对该主机地址跑诊断。
- **最近连接**：「会话」菜单 →「最近连接」**二级菜单**列出最近成功连接的主机（最多 8 条，新的在前、自动去重；
  会话菜单本身保持短），点一条即按与侧边栏一致的取密流程重连；主机被删除时自动从列表里消失。记录存进加密库 `settings` 的 `recent` 键，
  重启后仍在；仅存主机 id，不落任何凭据。
- **文件浏览与传输（SFTP）**：边栏「文件」页直接浏览远端目录（也可走「视图」菜单 / `Ctrl+Shift+B`），
  **复用当前 SSH 连接**的 SFTP 子系统（不新开连接、不再认证）。工具栏「上传」或直接把文件拖进面板即传到当前目录，
  拖动过程中面板底部浮一条「松开即上传 N 个文件到 <目录>」，光标停在文件夹行上时目录跟着换成那个子目录，
  行右键「下载到…」选保存位置即可下载；传输中显示字节进度与百分比，
  失败在面板与状态栏同时报错（单请求超时 120 秒，超时提示会点名该请求而不是干等），
  下载半途失败会删掉残缺本地文件。写入流水线 32 个在途请求 × 64 KiB 分片、读取并发 8，
  正好吃满 OpenSSH 默认 2 MiB 通道窗口，高延迟链路上也不会退化成「一发一收」。
  SFTP 通道登记进旁路集合，其字节不会串进终端；关标签时面板状态一并清空，传输任务随会话结束。
- **本机文件页（本机 ↔ 远端双栏）**：边栏「本机」页（`Ctrl+Shift+L` / 「视图」菜单）浏览本机目录，
  与「文件」页共用同一张表格——点击路径栏就地编辑（回车跳转，可直接输入 `D:\` 换盘），
  双击目录进入、双击文件用系统默认程序打开，列头排序 / 列宽拖拽 / 右键菜单全都有；
  底部是项目数与「显示隐藏文件」开关（Windows 看隐藏属性，Unix 看点开头），
  面板窄时自动收起时间 / 权限列。列出目录在后台线程跑，网络盘或超大目录不会卡住界面。
  跨栏传输走两边的行右键菜单：「文件」页文件行 →「下载到本机面板」直接落到本机页当前目录；
  本机页文件行 →「上传到远端当前目录」传到活动标签的 SFTP 目录。本机页没有打开目录、
  或活动标签不可写时，对应菜单项是灰的并在文案里写明原因。本机页当前目录与隐藏文件开关
  存加密库 `settings.local_files`，库不可用时降级 `settings.json`。
- **远程桌面（VNC / RDP）**：「会话」菜单 →「远程桌面…」或 `Ctrl+Shift+R` 新开一个桌面标签，
  标签内就地填地址（可写 `host:5901`）、端口与密码，表单右上角切 VNC / RDP，回车或点「连接」即建连——
  与终端共用同一栏标签，标签前有桌面类型图标。
  - VNC：RFB 3.3 / 3.7 / 3.8 协商、None / VNC 认证，编码支持 Raw / CopyRect / Hextile 与桌面尺寸变更
    （DesktopSize）；滚轮映射为 VNC 的按钮 4/5，远端发来的剪贴板直接写入本机。
  - RDP：IronRDP 客户端，TLS + CredSSP（NLA）登录，表单多填用户名与域，请求 1280×800 桌面；
    键盘按 US 布局扫描码发送，中文与改键字符走 Unicode 通道，鼠标 / 滚轮直发。
    RDP 暂不支持双向剪贴板与音频，只走 NLA（不支持关掉 NLA 的旧服务器），
    服务器证书不校验（读的是 IronRDP 默认的 TLS 后端）。
  工具条给「断开 / 自适应 / − / 100% / + / 捕获键盘 / 剪贴板」，右侧显示 `WxH · N fps`（悬停看远端名称）；
  捕获键盘后按键直接送远端，`Esc` 释放（未捕获时画面顶部有提示），点击画面即重新捕获。
  画面按窗口等比缩放并居中。连接失败就地显示原因，可「复制错误 / 修改参数 / 重试」。
  **密码只在本次连接的内存里**，不落盘、不进日志、不进命令行。
  RDP 依赖见 `Cargo.toml` 的 `[patch.crates-io]`：本地 `vendor/picky`、`vendor/sspi` 只把与本项目
  已发布加密依赖冲突的预发布 pin 跟到正式版，其余代码原样，理由写在注释里。
  SPICE 仍未实现：没有许可兼容的客户端库，评估写在路线图 P2。
- **端口转发（-L / -R / -D，规则可保存）**：走「终端」菜单 / `Ctrl+Shift+F` 切到边栏「转发」页。
  规则是「先保存、再开关」：页面默认只列**已保存的转发**，点底部「设置…」才展开新增 / 编辑表单；
  填方向（本地 / 远程 / 动态）、端口与目标地址后点「保存规则」，条目回到列表，
  每行一个开关即时启停，保存时勾「连接时自动开启」即可随连接拉起，不必每次重填。
  - 本地（-L）：本机监听 `127.0.0.1:<端口>`，连接经当前 SSH 连接转到**服务器视角**的目标地址（内网 Web、数据库皆可）；
  - 远程（-R）：向服务器申请 `127.0.0.1:<端口>` 监听（`tcpip-forward`），连接经 SSH 回到本机，
    适合把本地服务临时暴露给远端机器；
  - 动态（-D）：本机 `127.0.0.1:<端口>` 提供 **SOCKS5 代理**（仅无认证），目标由客户端逐条协商、
    在服务器侧解析，一个入口即可访问整个内网；目标不可达时回 `0x05` 让客户端立刻报错，而不是干等超时。
  监听**都只绑回环地址**，不对局域网开放（SOCKS5 无认证，更不该外露）。服务端 sshd 需放行 TCP 转发
  （`AllowTcpForwarding yes`，部分镜像默认 `no`）——被禁时本地端口能连上，但打开通道会被服务器拒绝。
  规则按 `user@host:port` 存进加密库 `settings` 表的 `forwards` 键
  （库不可用时退回 `settings.json`），同一方向同一监听端口视为同一条、原位覆盖；删除规则会先掐断其监听与活动连接。
  关标签或连接断开时监听与连接一并释放，端口不会残留占用；生效条数压在边栏「转发」图标的角标上，标题栏不再放转发按钮。
- **跳板机（ProxyJump）**：新建 / 编辑主机的表单里有「跳板机」下拉，默认「直连」，可改选另一台已保存主机；
  连接时先连跳板机、再经它的 `direct-tcpip` 通道连目标，终端里先打印一行「经跳板机连接：A → B」。
  目标是服务器视角的地址，所以填跳板机内网里才有的主机名 / IP 即可。约束：
  - 只支持**一级**跳板：下拉自动排除目标自己、以及已经挂着跳板机的主机（不让链变两级以上），保存时再次校验；
    删除跳板机会自动把引用它的主机改回直连。
  - 跳板机凭据只从**内存缓存或加密库**取：先单独连一次跳板机并勾「保存密码」（或把它设成私钥 / Agent），
    之后连目标时不再二次追问；取不到时状态栏给出「请先单独连接它并勾选保存密码」的提示，绝不为此弹窗或明文落盘。
  - 每一跳都独立做主机指纹校验（TOFU 写入加密库），任一跳指纹不符即整体拒绝连接。
  - 映射存进加密库 `settings` 表的 `jumps` 键（不新建列、不做 ALTER）；降级模式（无加密库）下拉只有「直连」。
- **`~/.ssh/config` 导入**：「会话」菜单或列表空白处右键「导入 ~/.ssh/config…」，
  读取 `HostName` / `User` / `Port` / `IdentityFile`，每个具体别名生成一台主机（展示名即别名）；
  通配符（`*` / `?` / `!`）与 `Match` 块跳过，同一别名只取第一块；按 `user@host:port` 或同名去重；
  私钥文件在本机不存在时改用 Agent 认证，避免导入后连不上。
- **分组与折叠持久化**：组顺序、折叠态（含内置「本地终端」分组）、主机归属与组内排序序列化成 JSON 存进加密库 `settings` 表的 `sidebar` 键
  （库不可用时退回 `settings.json`），重启原样恢复；刻意不给 `hosts` 表加列，免去加密库 ALTER 迁移。
  搜索时空分组隐藏、折叠的分组强制展开，命中的主机不会被藏起来。
- **布局**：左侧/右侧是一条统一的**边栏**（可拖拽宽度，WindTerm 式，拖到最小宽度停住），贴着窗口外缘的竖向导航在
  「主机 / 文件 / 本机 / 转发」四页之间切换；边栏位置可在「外观」设置里选左或右（导航栏始终在最外侧），选择写入加密库并跨重启保留。
  折叠 / 展开走「视图」菜单或 `Ctrl+B`，折叠后主区顶部不额外出现展开栏。
- **导航条学 RustRover**：最外缘那条 42px 窄栏**只画图标、不排文字**，页名交给悬停 tooltip（0.3 秒后浮出），
  当前页在外缘画一道强调色竖条，转发生效条数压成图标角标；窄栏独立于分隔面板，
  面板收起（`Ctrl+B` / 再点当前页图标）时它仍留在窗口外缘，主区因此能铺满整行宽度。
- **自定义标题栏**：应用自绘顶栏（`appears_transparent` + `app_owns_titlebar_drag`），左侧品牌标识与锁定提示，
  中间**多级菜单**按域分六档：「会话」（新建主机 / 导入 config / 最近连接 ▸ / 本地终端 / 设置 / 隐藏到托盘 / 退出）、
  「视图」（面板显隐与折叠 / 分屏 / 标签切换）、「终端」（查找 / 同步输入 / 命令广播 / 键宏 / 端口转发）、
  「凭据」「外观」「帮助」，一屏菜单不再堆到底，右侧只留口令档才出现的 🔑 / 🔒，最右为系统窗口控件；
  「文件 / 本机 / 转发」的页面入口同时也在边栏导航里。
  设置与侧边栏折叠的常驻按钮已撤掉：前者收进「会话 → 设置…」与「外观」各分页，后者走「视图」菜单 / `Ctrl+B`。
  拖拽与窗口控件走 `WindowControlArea` 命中区，
  交互控件排在 Drag 区**之外**（Windows 的 `WM_NCHITTEST` 只认第一个命中的控制区，父级 Drag 会吞掉栏内按钮点击）。
  菜单项挂的是 rgpui **action**，有快捷键的项右侧自动渲染按键徽标（`Ctrl+N` / `Ctrl+Shift+T` / `Ctrl+B` / `Ctrl+,` / `Ctrl+T` / `Ctrl+Shift+M`），
  标签里不再手写快捷键文字，「帮助」菜单只留版本号。
- **设置界面**：「会话 → 设置…」（`Ctrl+,`）或「外观」菜单中的各分页入口打开，**左侧竖排分页导航**——「凭据库与主密码」/「外观」/「状态栏」/「终端」/「会话」，右侧为当前分页内容；
  弹窗固定大小，切分页不会忽大忽小，内容超出时分页自身滚动，后续设置项继续加分页即可。
- **主题**：明 / 暗切换，配色全部取 rgpui 全局 `Theme` 语义色，选择持久化到加密库。
- **界面语言**：简体中文 / English 即时切换，「外观」菜单与设置「外观」分页都有入口。
  **中文原文即翻译 key**（rgpui `I18nManager` 缺词条时原样返回），所以没译全的句子只会退化成中文，
  不会出现 `settings.foo` 这类占位符。英文表 `assets/locales/en.json` 用 `include_str!` 编译进二进制，
  不依赖运行时目录；占位符统一 `{name}` 形式。语言存加密库 `language` 键，另在 `~/.ruterm/locale.txt`
  留一份启动镜像，让首帧（早于解锁）就用对语言。已有词条：菜单 / 标题栏 / 设置 / 状态栏 / 文件与转发页。
- **终端外观**：「终端」分页调字号（10–32px）、行高与配色方案，内置 9 套预设
  （One Dark/Light、Solarized、Dracula、Nord、Gruvbox、GitHub Light），改动即刻刷到所有已开终端。
  选「自定义」后可逐项编辑前景 / 背景与 16 色（8 普通 + 8 明亮）：`#RGB` / `#RRGGBB` 输入即时生效，
  色块实时预览，非法格式保留上一个有效色，「恢复 One Dark」一键回到默认；同样写入加密库并随偏好持久化。
  终端内容区四周留内边距，底色随配色预设的 `background`，不会在浅色主题下显成一圈白框。
- **凭据存储**：主机配置、应用设置、known_hosts 合并为**一个加密文件** `ruterm.db`
  （toasty ORM + turso AEGIS-256 页级加密），不再有零散的 JSON / 文本档。
  密码 / 私钥口令另有**第二层字段加密**：`hosts.password` 列存 AES-256-GCM 密文
  （字段密钥由主密钥域分离派生，每次写入随机 nonce），即使库文件被离线复制也只多一道锁。
  **内嵌私钥**同样走这层字段加密，存在 `settings.host_keys`（host_id → 密文 JSON），
  不占 `hosts` 列以避开加密库 ALTER 迁移；更换主密码搬迁库时解密后用新字段密钥重新加密。
- **便携 / 全局双模式**：exe 同目录**存在** `data/` 文件夹即为便携模式（全部数据随 exe 走，U 盘可带），
  否则为全局模式 `~/.ruterm`。判定只探测、不自动创建目录。
- **两档解锁**：默认（全局与便携皆同）用系统凭据管理器里的随机主密钥，启动零输入、开箱即用；
  主密码（argon2id 派生）为**可选增强**，在设置里随时**设置 / 更换 / 取消**：设置后每次启动需输入口令，
  库文件可凭同一口令拷到另一台机器解锁；取消则换回免密档（库重新绑定本机）。已设主密码时标题栏出现
  🔒，一键锁定凭据库（锁定后只剩 🔑 解锁入口）。⚠️ 忘记主密码 = 数据不可恢复（无任何后门），请牢记。
- **状态栏**：底部常驻，左侧整体状态 + 活动会话地址/认证方式 + 远程主机信息 + 终端读数，右侧会话计数。
  连接成功后状态切到「已连接 地址」；远程 OS / 内存 / 磁盘 / 负载 / uptime 由后台一条
  exec 通道**每 5 秒刷新**（脚本循环输出、以 `end` 行分块解析，探测失败则该条目不显示），
  负载等随会话变化的指标不会再停在连接那一刻的旧值。
  终端读数四项：尺寸 `75×35`、光标 `行 4 列 36`、`回滚 N 行`（滚动进历史才出现）、`选区 N 行`（选中才出现），
  本地终端与远程会话都适用；读数直接取活动终端的当前帧，纯本地计算，不产生任何 IO。
  要显示哪些条目由设置里的「状态栏」分页勾选（会话信息、远程指标、终端状态三组），改动即时生效并存入凭据库。
- **系统托盘**：品牌图标 + 悬停提示（`RuTerm 拾连 · N 个会话`）+ 右键菜单：上半部分**动态列出当前会话**
  （`●` 为活动标签、`○` 为其它标签），点一条即恢复窗口并切到该标签；下半部分为显示主界面 / 退出。
  点窗口关闭按钮隐藏到托盘，会话后台保活；标签增减、切换时菜单与提示自动刷新。
- **单实例守卫**：启动时先在 `127.0.0.1:47122` 占一个带口令的环回监听。抢到即为主实例，后台守着这个端口；
  没抢到说明已有实例在跑（多半藏在托盘里），于是**敲门**——写一行令牌、等它回同样的令牌，然后唤醒它的窗口到前台并自己退出，
  不会再开出第二个进程抢同一份加密库、也不会托盘里叠出两个图标。端口被别的程序占用时令牌对不上，
  宁可直接启动也不误伤（`src/instance.rs`，握手 600ms 超时）。
- **品牌图标**：多尺寸 `.ico` 经 `build.rs` + winresource 嵌入 exe（文件 / 任务栏 / 标题栏）。

## 键宏使用示例

键宏只做一件事：把若干步「字面文本」按顺序写进**当前活动**终端，步与步之间可以等一会儿。
以下例子都从「终端」菜单 →「键宏…」（`Ctrl+Shift+M`）→「新建宏」填。

### 例 1 · 一条命令重启服务

名称 `重启 api`，触发键 `ctrl-alt-r`，一步：

```
docker compose -f /srv/app/docker-compose.yml restart api\n
```

末尾的 `\n` 是回车。不写它，命令只会打在提示符上、不执行。

> 上面五步的字节流已在真机（Docker `test@localhost:2222`）上按 `MacroStep::to_bytes()`
> 原样回放验证过：带 `\n` 的步执行、不带 `\n` 的步只打字、`\\n` 交给远端 `printf` 打出两行。

### 例 2 · 巡检三连，中间给远端留反应时间

名称 `k8s 巡检`，触发键 `f9`，三步：

| 步 | 发送内容 | 步后延迟 |
|----|----------|----------|
| 1 | `kubectl get pods -A\n` | 800 |
| 2 | `kubectl top pods -n prod\n` | 500 |
| 3 | `kubectl get events -n prod --sort-by=.lastTimestamp\n` | 0 |

延迟是「发完本步之后」再等，不是发送前等；填 0 表示立刻接下一步。

### 例 3 · 进项目环境并跟日志

| 步 | 发送内容 | 步后延迟 |
|----|----------|----------|
| 1 | `cd /srv/app\n` | 300 |
| 2 | `source env/bin/activate\n` | 300 |
| 3 | `tail -f log/app.log\n` | 0 |

### 例 4 · 只打字、不执行

发送内容填 `ssh root@192.168.31.222`（不带 `\n`）。适合 `rm`、`DROP TABLE` 这类
希望先眼看一遍再自己按回车的高危命令。

### 例 5 · 借 Tab 补全长路径

`cd /srv/de\t` —— `\t` 会真的送一个 Tab 进 shell，触发文件名补全；歧义时补出公共前缀，
剩下的手敲。四个转义：`\n` 回车、`\t` Tab、`\e` ESC、`\\` 一个反斜杠，其余字符按字面发送。

### 触发键怎么选

- 触发键一栏**点一下进入录制态，直接按下想要的组合键**就录好了（再点别处或 Esc 退出录制，× 清空＝不绑键）；
  手输 `ctrl-alt-j` 这样的串同样认。
- 必须带 Ctrl 或 Alt（如 `ctrl-alt-j`），或者直接用 `F1`–`F12`。
- 不能占用 shell 控制字符（`ctrl-c` / `ctrl-d` / `ctrl-r` …）和应用已有快捷键（`ctrl-shift-m`、
  `ctrl-shift-d` 等），保存时直接报冲突，不会静默吃掉终端行为。
- 一个组合只能绑一条宏，先保存的赢。
- 只在终端持有焦点时拦截；焦点在边栏、弹窗里时按键照常走。

### 几条边界

- 只发给当前活动那一个终端。要同时打给多台，用「同步输入」或「命令发到所有会话…」。
- 列表行的开关关掉后，触发键不再拦截，但仍能点 ▶ 手动执行。
- 没有录制、循环、条件判断，也不能按会话分别绑定。
- 「导出…」得到 JSON，换机器或给同事直接「导入…」；数据本身存在加密凭据库的 `settings` 表。

## 构建与运行

```bash
cargo run                 # 启动 GUI 会话管理器
cargo run --release       # 发布构建
cargo build --release     # 产出可执行文件
```

要求 Rust 2024 edition 工具链（`Cargo.toml` 中 `edition = "2024"`）。

### 命令行快速连接

```bash
ruterm [user@]host[:port] [-i keyfile]
```

- 用户名缺省时取 `$USER` / `$USERNAME`，再回退 `root`；端口缺省 22。
- 密码认证通过环境变量提供：`ruterm_PASSWORD=xxx ruterm user@host`（命令行不接受密码参数）。
- 不带任何参数即进入 GUI 主界面。
- 快速连接同样在 GUI 窗口内进行：已设置主密码时，若要读取库内已保存的凭据，先在主界面完成解锁
  （未解锁时指纹校验回退旧 `known_hosts` 文本，行为与降级模式一致）。

## 本地文件

数据目录由启动模式决定：**exe 同目录存在 `data/` 文件夹 → 便携模式**（下表路径换成 `<exe 目录>/data/`），
否则全局模式 `~/.ruterm`。判定只探测不创建——想切换便携，手动在 exe 旁建一个空 `data/` 即可。

| 路径 | 内容 |
|------|------|
| `ruterm.db` | **唯一数据文件**（toasty ORM + turso，AEGIS-256 页级加密）：`hosts`（主机配置 + 可选保存的密码/口令）、`settings`（主题等应用设置；`host_keys` 存内嵌私钥的字段密文）、`known_hosts`（主机指纹）三张表 |
| `kdf-salt.bin` | argon2 派生主密钥用的随机盐（**公开参数，非秘密**）；更换主密码时重新生成 |
| `unlock.txt` | 解锁后端标记（`keyring` / `passphrase`），非敏感明文，用于决定启动是否弹解锁窗 |
| `vault.db` → `vault.db.migrated` | 旧版手写 SQL 加密库；首启读出迁入 `ruterm.db` 后改名保留 |
| `sessions.json` → `sessions.json.migrated` | 旧版主机构档；迁入加密库后改名保留（加密库不可用时才继续读写原文件） |
| `settings.json` → `settings.json.migrated` | 旧版应用设置（主题、状态栏偏好、终端偏好）；迁入 `settings` 表后改名保留 |
| `known_hosts` → `known_hosts.migrated` | 旧版指纹文本；迁入 `known_hosts` 表后改名保留 |
| `ruterm.db.keyring-bak` | 设置 / 更换 / 取消主密码时被替换下的旧库备份（数据校验通过后自动清理） |

Windows 下 `~` 取 `%USERPROFILE%`，其他平台取 `$HOME`。

**主密码须知**：主密码是**可选**加固项——不设也能正常用（默认走本机凭据管理器免密解锁，状态栏会给出建议）。
在「会话 → 设置…」→「凭据库与主密码」里可随时**设置 / 更换 / 取消**：设置或更换都需先输入并确认新口令
（已是口令档时还要先验证当前主密码，防止托盘常驻时被他人直接改密钥）；取消则把库密钥换回凭据管理器里的
随机密钥，此后启动不再输入口令。口令错误可重试，连续失败想放弃就点"退出应用"——未解锁的运行不落任何秘密。
**忘了主密码数据无法找回**（Argon2 无后门）；免密档（keyring）下拷贝 `ruterm.db` 到其他机器无法解密，
需要随身携带就把主密码设上。

## 模块结构

```
src/
  main.rs       # 应用入口：动作定义（actions!）、全局快捷键绑定、建窗 + 系统托盘 + 单实例守卫
  instance.rs   # 单实例：环回端口占坑 / 令牌敲门 / 唤醒已藏起来的窗口
  app/          # 应用层按功能拆分（mod.rs 持有 RuTermApp 状态与根渲染调度，其余为同功能 impl 块）
    tabs.rs / connect.rs / hosts.rs / host_form.rs / files.rs / local_files.rs / forwards.rs / local_shells.rs
    settings.rs（含偏好类型 prefs.rs、外观 appearance.rs）/ sidebar.rs / status_bar.rs
    terminal_ops.rs / title_bar.rs / vault_ui.rs / macros_ui.rs（键宏管理器）/ widgets.rs
  macros.rs     # 键宏：触发键校验与规范化、步骤转义、JSON 序列化（含单测）
  session.rs    # 会话桥接：rgpui-term 外接 IO ⇄ russh 双向字节流（上行泵线程 + 转发任务）+ 跳板机链式建连 + exec 远程信息探测 + SFTP 传输 / 端口转发（含 SOCKS5 握手）指令调度
  ssh.rs        # SSH 引擎：russh client::Handler、指纹校验（优先查加密库，降级回文本文件）、旁路通道过滤
  telnet.rs     # Telnet 会话：tokio TCP + 最小 IAC 协商（ECHO/SGA 接受、NAWS 上报、子协商丢弃、上行 0xFF 双写），灌同一个外接 IO 后端（含单测）
  transfer.rs   # SFTP 上传 / 下载：复用当前 SSH 连接开子系统，分块搬运 + 节流进度 + 目录落点补文件名（含单测）
  remote.rs     # 远程主机信息：POSIX 探测脚本 + key=value 解析 + 可勾选指标枚举（含单测）
  config.rs     # 连接目标：命令行解析 + 主机账号 → SshTarget（含跳板机链 jump_chain）
  ssh_config.rs # `~/.ssh/config` 解析：Host/别名、HostName/User/Port/IdentityFile，跳过通配符与 Match（含单测）
  paths.rs      # 存储模式判定（便携 `data/` 或全局 `~/.ruterm`）与所有数据文件路径
  local_shell.rs # 本机 shell 探测（PATH / 安装目录 / `wsl -l`）+ 启动参数分词 / 环境变量解析（含单测）
  sessions.rs   # 降级路径：旧版主机/设置 JSON（SessionStore）+ 迁移后改名标记
  vault.rs      # 单文件加密库：toasty 模型（hosts/settings/known_hosts）+ keyring / argon2 主密码 + 旧文件一次性迁移
```

数据流：下行 `SshTerminalHandler::data` → `FeedHandle::feed` 灌入终端；
上行终端阻塞通道 → 专用泵线程 → tokio 通道 → 写入 russh 通道（按键 / 应答 / 尺寸变化）。
